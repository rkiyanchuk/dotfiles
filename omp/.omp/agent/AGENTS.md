# Agent Configuration

## Notes & knowledge base

Notes are stored in Obsidian vaults:

- **Profession**
  (`~/Library/Mobile Documents/iCloud~md~obsidian/Documents/Profession`):
  information security, cybersecurity, software engineering, cryptography, and
  all work-related topics.

- **Notes** (`~/Library/Mobile Documents/iCloud~md~obsidian/Documents/Notes`):
  general knowledge, personal notes, and everyday life.

When notes need to be created or updated, use the `obsidian` skills to read and
write files in the appropriate vault — not the memory system.
